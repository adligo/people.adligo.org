# people.adligo.org

This is public directory of people associated with the Adligo.org codebase.  If your interested in contributing to Adligo.org in some manor please follow these instructions to add yourself to our directory;

### Prerequsites

Install [GitBash](https://git-scm.com/install/) or any other Git tool.  
Note GitBash is our favored tool at Adligo.org.

### Find Someone

If you want to search this directory simply download it and use Spotlight, Eclipse, DaisyDisk or any local search tool.

### Step One

Fork the [https://github.com/adligo/people.adligo.org](https://github.com/adligo/people.adligo.org) repository;

### Step Two

Clone your fork onto your hard drive (replace yourUid with your GitHub user id) i.e.;

```
 git clone git@github.com:<yourUid/>/people.adligo.org.git
 git clone git@github.com:someone/people.adligo.org.git
```

### Step Three

Create create a markdown file in the e-mails folder using one of the following examples;

- [scott@adligo.com](e-mails/com/adligo/scott.md)

Note: for commonly used email providers like gmail we add a sub folder (i.e. a, b, c, 1, 2, 3 etc).
 
- [asfkl345lkja@gmail.com](e-mails/com/gmail/a/asfkl345lkja.md)
- [blkjsdf@gmail.com](e-mails/com/gmail/b/blkjsdf.md)

### Step Four

Please include your Discord User Id so we can tell who is who in the chat.
Also, add anything you want the rest of us to know about you, were usually friendly :)

### Step Five

Create a [pull request](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/creating-a-pull-request) so that I can merge your info into the main branch;
